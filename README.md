# Simulasi Mesin Kepang Tali

Prototipe web untuk menguji antarmuka dan animasi konseptual mesin kepang dengan pilihan 16, 24, 32, dan 48 bobin.

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages dari **Settings → Pages** dengan sumber **Deploy from a branch**, branch `main`, folder `/ (root)`.

## Kontrol
- Pilih jumlah bobin: 16, 24, 32, atau 48.
- Atur kecepatan.
- Tampilkan/sembunyikan benang dan nomor bobin.
- Mulai, jeda, atau reset animasi.

## Catatan akurasi
Animasi saat ini adalah konsep visual, bukan model teknik mesin KBL yang terverifikasi. Jalur carrier sebenarnya perlu dicocokkan dengan foto/video mekanisme jalur dan horn gear mesin asli sebelum dianggap akurat atau digunakan sebagai panduan operasi.
